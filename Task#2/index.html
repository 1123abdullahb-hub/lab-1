Networking Core: IANA, RIR & ISP

Understanding global internet governance and IP allocation is crucial for modern software systems:

  • IANA (Internet Assigned Numbers Authority): Manages the global coordination of the DNS root, IP addressing, and other internet protocol resources.
  • RIR (Regional Internet Registry): Allocates IP addresses and ASNs regionally (e.g., APNIC for Asia-Pacific).
  • ISP (Internet Service Provider): Connects end-users to the global internet backbone using allocations from RIRs.
